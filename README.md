# Для моей красноволосой бестии ❤️

Готовый статический сайт для GitHub Pages. Никакой сборки не требуется.

## Публикация через GitHub Pages

1. Создай новый репозиторий на GitHub, например `for-masha`.
2. Загрузи **всё содержимое этой папки** в корень репозитория.
3. Открой `Settings` → `Pages`.
4. В `Build and deployment` выбери `Deploy from a branch`.
5. Выбери ветку `main` и папку `/(root)`, затем `Save`.
6. После публикации GitHub покажет адрес сайта вида `https://USERNAME.github.io/for-masha/`.

## Музыка

Сейчас музыка генерируется браузером как очень тихий ambient и запускается только после нажатия «Открыть». Поэтому отдельный MP3-файл не нужен.

Если позже захочешь вашу конкретную песню, можно заменить ambient на обычный `<audio>`.

## Счётчик

Количество дней рассчитывается автоматически от **20.06.2026** по текущей локальной дате телефона. Менять число вручную не нужно.

## Скрытые записки

- Сердечко на первом совместном фото.
- Маленькое сердечко на фото у зеркала.
- «не нажимать» возле фото с поцелуем в щёку.
- Настоящая пасхалка: четыре быстрых нажатия на фразу «Красноволосая бестия собственной персоной.»

## QR-код

Сначала опубликуй сайт и получи финальную ссылку. QR-код лучше генерировать уже по этой ссылке — иначе после изменения адреса придётся печатать новый.
